# 📷 Photo Face Sorter — 人脸识别照片分类系统

## 项目简介

**Photo Face Sorter** 是一个基于深度学习的人脸识别与照片自动分类系统。用户只需上传照片，系统便能自动检测并识别图中人脸，将照片归类到对应的人物文件夹中。对于首次出现的未知人脸，用户可以手动输入姓名，系统会自动触发增量训练，在不重新训练全部数据的前提下将新人物加入识别库，实现持续学习与扩展。

整个系统基于 **Flask** 提供 Web 界面，后端使用 **OpenCV DNN** 进行人脸检测，结合 **PyTorch ResNet-18** 迁移学习模型完成人脸分类，适合用于个人相册整理、批量照片管理等场景。

---

## ✨ 项目优点

### 1. 🖥️ 操作简便的 Web 界面
- 提供基于 Flask 的网页界面，通过浏览器即可完成照片上传与分类
- 无需命令行操作，普通用户也能轻松上手

### 2. 🧠 支持增量学习，持续扩展识别能力
- 遇到低置信度的未知人脸时，用户可输入姓名，系统自动保存样本并触发增量训练
- 增量训练在后台线程中进行，不阻塞 Web 界面，训练完成后自动重载模型
- 无需从头重训，大幅降低了时间与计算成本

### 3. ⚡ 高效的深度学习架构
- 采用轻量级 **ResNet-18** 作为骨干网络，参数量远少于 ResNet-50/101，推理速度更快
- 利用 **迁移学习**（ImageNet 预训练权重）加速收敛，减少所需训练数据量
- 自动检测并使用 GPU（CUDA），无 GPU 时无缝回退到 CPU

### 4. 🔍 可靠的人脸检测
- 使用业界成熟的 **OpenCV SSD300**（Caffe 模型）进行人脸检测，鲁棒性强
- 内置边界裁剪处理，防止人脸区域超出图像边界导致的错误
- 置信度阈值过滤（0.5），有效减少误检

### 5. 🗂️ 智能结果分类与管理
- 识别成功的照片自动保存至 `result/{人物姓名}/` 目录，一目了然
- 目录结构清晰，便于后续浏览与管理

### 6. 🔧 灵活可扩展的架构
- 分类类别数动态适配，无需修改代码即可支持任意数量的人物
- 模型训练与推理解耦，可单独替换检测或分类模块
- 支持 JPG、JPEG、PNG、BMP 等常见图片格式

### 7. 📦 代码精简、结构清晰
- 代码简洁，易于阅读和二次开发
- 训练脚本（`train.py`）与应用脚本（`app.py`）职责分离，结构清晰

## 🚀 运行方法

### 1. 准备训练数据

将各人物的训练照片放入 `model/dataset/` 目录，按人物分子目录存放：

```
photo-face-sorter/
├─model
│  ├─dataset
│  │  ├─000        ← 第1个人物的照片
│  │  ├─001        ← 第2个人物的照片
│  │  ├─002
│  │  └─...
│  └─__pycache__
├─result           ← 分类结果输出目录
├─static
│  └─uploads
└─templates
```

### 2. 训练模型

```bash
python model/train.py
```

运行后自动生成模型并保存为 `model/model.pth`。

### 3. 启动 Web 应用

```bash
python app.py
```

直接运行 `app.py` 即可自动加载已训练的模型，在浏览器中打开提示的地址，上传照片即可开始人脸识别与分类。
